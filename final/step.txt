PHASE 1 — THÁNG 1: NGHIÊN CỨU & DỮ LIỆU
================================================================================

[STEP 1.1] EDA trên VLSP 2018 (ƯU TIÊN LÀM NGAY - đã có data)
  - Phân tích phân phối nhãn 5 aspects: food, price, service, ambiance, location
  - Kiểm tra class imbalance ratio
  - Thống kê độ dài câu trung bình
  - Phát hiện missing labels per aspect
  - Output: notebooks/01_EDA.ipynb

[STEP 1.2] Refactor Preprocessing (đang có Preprocessing.ipynb)
  - Tách thành module src/data/preprocessor.py
  - Thêm: underthesea tokenization, Unicode normalization
  - Xử lý class imbalance: SMOTE / weighted sampling
  - Output: src/data/preprocessor.py

[STEP 1.3] Data Augmentation (tùy chọn)
  - Scrape thêm Google Maps reviews với timestamp
  - Format chuẩn: {text, timestamp, restaurant_id, aspects_labels}
  - Output: data/augmented/

================================================================================
PHASE 2 — THÁNG 2-3: ABSA MODULE
================================================================================

[STEP 2.1] Baseline Models
  - TF-IDF + SVM (per aspect)
  - TF-IDF + Logistic Regression (đang có trong Preprocessing.ipynb)
  - mBERT fine-tuned
  - Output: notebooks/03_Baseline_Models.ipynb

[STEP 2.2] PhoBERT Multi-task Model
  - Kiến trúc:
      PhoBERT-base-v2
        └── Shared Encoder
            ├── Branch ACD: Multi-label (5 aspects) → BCELoss
            └── Branch SPC: 3-class per aspect      → CrossEntropyLoss
  - Target: Macro F1 ≥ 80%
  - Output: src/absa/model.py, src/absa/train.py

[STEP 2.3] Thực Nghiệm & So Sánh
  ┌─────────────────────────┬──────────┬──────────┐
  │ Model                   │ ACD F1   │ SPC F1   │
  ├─────────────────────────┼──────────┼──────────┤
  │ SVM + TF-IDF            │ baseline │ baseline │
  │ mBERT                   │ ?        │ ?        │
  │ PhoBERT single-task     │ ?        │ ?        │
  │ PhoBERT multi-task      │ ≥80%     │ ≥80%     │
  └─────────────────────────┴──────────┴──────────┘

================================================================================
PHASE 3 — THÁNG 2-3: TREND DETECTION (SONG SONG PHASE 2)
================================================================================

[STEP 3.1] BERTopic Setup
  - Group reviews by month/quarter (temporal windows)
  - Apply BERTopic per window
  - Merge topics via cosine similarity across windows
  - Output: src/trend/bertopic_model.py

[STEP 3.2] Signal Classification
  - Phân loại: noise / weak signal / strong signal
  - Dựa trên: tần suất topic + tốc độ tăng trưởng
  - Output: trend_score per (restaurant, aspect, time)
  - Output file: src/trend/trend_scorer.py

================================================================================
PHASE 4 — THÁNG 3-4: RAG CHATBOT + BACKEND + FRONTEND
================================================================================

[STEP 4.1] Vector Database Setup
  - Tool: ChromaDB (prototype) → so sánh Weaviate
  - Document schema:
      {
        "restaurant_id": str,
        "name": str,
        "review_text": str,
        "absa_scores": {food: 0.8, price: -0.2, ...},
        "trend_score": float,
        "timestamp": datetime,
        "embedding": vector[768]
      }
  - Output: src/vectordb/schema.py, src/vectordb/indexer.py

[STEP 4.2] RAG Pipeline
  - LangChain flow:
      Query → Intent Analysis
            → Hybrid Retrieval (dense + BM25)
            → Prompt Augmentation (context + taste_profile)
            → LLM (Llama 3 / GPT)
            → Guardrail check
            → Response
  - Output: src/rag/pipeline.py, src/rag/prompts.py

[STEP 4.3] FastAPI Backend
  - POST /chat           → RAG chatbot
  - GET  /restaurants    → List + filter
  - GET  /trends         → Trend dashboard data
  - POST /user/profile   → Taste profile update
  - Output: backend/

[STEP 4.4] React Frontend
  - 3 màn hình chính:
      1. ChatBox    → giao tiếp với RAG chatbot
      2. Dashboard  → biểu đồ trend theo aspect/thời gian (Recharts)
      3. Restaurant Card → hiển thị ABSA scores dạng radar chart
  - Output: frontend/

================================================================================
PHASE 5 — THÁNG 4-5: ĐÁNH GIÁ & HOÀN THIỆN
================================================================================

[STEP 5.1] RAGAS Evaluation
  - Metrics mục tiêu:
      context_precision  ≥ 0.80
      faithfulness       ≥ 0.85
      answer_relevancy   ≥ 0.80
      hallucination rate: giảm ≥ 30% so với LLM thuần
  - Output: src/evaluation/ragas_eval.py, notebooks/06_RAG_Evaluation.ipynb

[STEP 5.2] User Study
  - Tối thiểu 20 người dùng
  - Thang Likert 5 mức: hữu ích, chính xác, trải nghiệm
  - Target: ≥ 4.0/5.0
  - Output: src/evaluation/user_study.py

[STEP 5.3] Viết Luận Văn
